 The web dashboard requests telemetry updates only once every second (setInterval at 1000ms), making the radar and distance readouts blind to fast changes.  

 Blocking Ultrasonic Scans: The ultrasonic_ranging() function uses hardcoded delay(500) and delay(200) pauses to move the servo and wait for echoes, freezing code execution for nearly 2 seconds per scan.

Autonomous Mode Lockouts: While running autonomous loops (ObstacleAvoidance() or LineTracking()), the rover blocks manual keyboard or pad inputs via driveOK(), making manual controls unresponsive until the mode is explicitly stopped.
